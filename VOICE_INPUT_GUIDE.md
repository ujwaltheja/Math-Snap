# Voice Input Feature - User Guide

## 🎤 Automatic Voice Answer Entry

MathSnap now supports **hands-free voice input** for answering math problems! No need to type - just speak your answer and it automatically fills the answer field.

## How It Works

### 1. **Tap the Microphone Button**
   - Look for the animated microphone button (🎤) next to the answer input field
   - Tap it to start voice recognition

### 2. **Speak Your Answer**
   - When listening, the mic button turns **red** and **pulses**
   - Simply speak the number clearly
   - Examples: "fifteen", "42", "one hundred twenty"

### 3. **Auto-Fill Magic**
   - Your spoken number **automatically appears** in the answer field
   - No need to press submit or confirm
   - The answer is instantly recognized and filled

### 4. **Submit When Ready**
   - Review the auto-filled answer
   - Tap "Submit" to check if you're correct

## Visual Feedback

| State | Appearance | Meaning |
|-------|-----------|---------|
| 🎤 Gray | Normal mic icon | Ready to listen |
| 🎤 Red Pulsing | Animated red icon | Actively listening |
| ✅ Number appears | Text in field | Voice recognized! |
| ❌ Error message | Red warning card | Recognition failed |

## Voice Recognition Features

### Supported Input
- **Numbers**: "5", "fifteen", "42", "one hundred"
- **Digits**: Spoken digit-by-digit "one five" = 15
- **Word Numbers**: "zero" through "ten" (and beyond as digits)

### Smart Recognition
- Automatically extracts numbers from speech
- Converts word numbers to digits
- Filters out non-numeric content
- Handles various accents and speaking styles

## Error Handling

If voice recognition fails, you'll see helpful error messages:

| Error | Cause | Solution |
|-------|-------|----------|
| "No match found" | Unclear speech | Speak more clearly |
| "No speech input" | Too quiet | Speak louder |
| "Insufficient permissions" | Mic blocked | Grant mic permission |
| "Network error" | Connection issue | Check internet |

## Permissions

### First Time Use
- App will request **microphone permission**
- Tap "Allow" to enable voice input
- Permission is remembered for future use

### Managing Permissions
- Go to: **Settings → Apps → MathSnap → Permissions**
- Toggle microphone access as needed
- Voice button disabled if permission denied

## Tips for Best Results

### ✅ Do This
- Speak clearly and at normal pace
- Use a quiet environment
- Hold phone normally (not too far)
- Say the complete number
- Wait for the red pulse before speaking

### ❌ Avoid This
- Don't speak too fast or mumble
- Avoid noisy backgrounds
- Don't cover the microphone
- Don't say extra words ("the answer is 5" → just say "5")

## Kid-Friendly Mode

Voice input is **perfect for kids** who:
- Are learning to count
- Can't type quickly yet
- Find keyboards difficult
- Prefer speaking over typing

### Parent Tips
- Practice saying numbers clearly
- Make it a game: "Say the answer!"
- Encourage proper pronunciation
- Celebrate successful recognitions

## Privacy & Security

### Your Voice Data
- **Processed locally** on your device
- **No audio stored** permanently
- Uses Android's built-in speech recognition
- **No data sent** to MathSnap servers

### Offline Mode
- Voice recognition requires internet connection
- Uses Google's speech services
- Fallback to keyboard if offline

## Troubleshooting

### Voice Input Not Working?

1. **Check Permissions**
   - Settings → Apps → MathSnap → Permissions → Microphone

2. **Test Microphone**
   - Try voice typing in another app
   - Ensure mic is not muted

3. **Update App**
   - Check for MathSnap updates
   - Ensure you have version 1.0.0+

4. **Restart App**
   - Close and reopen MathSnap
   - Try voice input again

### Mic Button Grayed Out?
- Permission not granted
- Speech services unavailable
- Device doesn't support speech recognition
